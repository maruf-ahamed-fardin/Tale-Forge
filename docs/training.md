# Training

TaleForge will fine-tune an existing open-source base model with LoRA or QLoRA.

It will not train a foundation model from scratch.

Later phases will add:

- Dataset versioning.
- Configurable base model selection.
- Tokenization.
- Story-level train/validation split.
- Background training jobs.
- Adapter saving.
- Google Colab notebook support.
- Model version registration.

The goal is to approximate stylistic patterns while generating original stories. Fine-tuning cannot guarantee perfect reproduction of a writing personality.
